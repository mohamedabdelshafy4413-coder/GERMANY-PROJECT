# GERMANY Export Growth Study

Professional Streamlit dashboard for NEGPI / GERMANY export market development.

## Scope
- Brand architecture & positioning
- GERMANY product portfolio
- Top 30 export markets
- 7 strongest market-entry plays
- SWOT
- 1,000 target-account architecture
- importer/distributor keyword engine
- 7-email export campaign
- 90-day go-to-market plan
- export economics & KPI tree

## Brand Platform
**GERMANY — Care for Every Stage.**  
Reliable protection. Everyday comfort. Complete care.

**Primary CTA:** Bring GERMANY to Your Market — Request Distributor Pricing.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud
Use this repository and set the main file path to `app.py`.

## Notes
Market scores are strategic prioritization indicators for planning and are not guaranteed profit or sales forecasts. Commercial decisions should be validated against current pricing, compliance, freight, buyer activity and payment terms.
